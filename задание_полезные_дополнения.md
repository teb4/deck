 ### 1. @REPLACE <addr> <sed-expression> — regex-замена в payload                                                                
                                                                                                                                 
 Синтаксис:                                                                                                                      
                                                                                                                                 
 ```                                                                                                                             
   @REPLACE 4-50                                                                                                                 
   s/foo/bar/g                                                                                                                   
   @END                                                                                                                          
 ```                                                                                                                             
                                                                                                                                 
 Что делает:                                                                                                                     
 - Payload — одна строка sed-выражения s/pattern/replacement/flags                                                               
 - Применяется ко всем строкам диапазона addr                                                                                    
 - g — все совпадения в строке, без g — первое совпадение                                                                        
                                                                                                                                 
 Примеры:                                                                                                                        
                                                                                                                                 
 ```bash                                                                                                                         
   # Заменить "foo" на "bar" во всех строках 4–50                                                                                
   @REPLACE 4-50                                                                                                                 
   s/foo/bar/g                                                                                                                   
   @END                                                                                                                          
                                                                                                                                 
   # Удалить ведущие пробелы в строках 10–20                                                                                     
   @REPLACE 10-20                                                                                                                
   s/^\s+//                                                                                                                      
   @END                                                                                                                          
                                                                                                                                 
   # Заменить с захватом групп                                                                                                   
   @REPLACE 4-50                                                                                                                 
   s/(temp)/\1_celsius/g                                                                                                         
   @END                                                                                                                          
 ```                                                                                                                             
                                                                                                                                 
 Почему полезно:                                                                                                                 
 - Deck-editor + regex = замена sed для диапазона строк                                                                          
 - Работает с одинаковыми строками (sed не может)                                                                                
 - Один вызов — одна атомарная операция

 ### 2. @APPEND — добавить строки в конец файла                                                                                  
                                                                                                                                 
 Синтаксис:                                                                                                                      
                                                                                                                                 
 ```                                                                                                                             
   @APPEND                                                                                                                       
   new line 1                                                                                                                    
   new line 2                                                                                                                    
   @END                                                                                                                          
 ```                                                                                                                             
                                                                                                                                 
 Что делает:                                                                                                                     
 - Добавляет payload в конец файла                                                                                               
 - Не требует get() чтобы узнать последнюю строку                                                                                
 - Payload обязателен (не может быть пустым)                                                                                     
                                                                                                                                 
 Примеры:                                                                                                                        
                                                                                                                                 
 ```bash                                                                                                                         
   # Добавить одну строку в конец                                                                                                
   @APPEND                                                                                                                       
   {"sensor": "temp", "value": 30.0, "unit": "C"}                                                                                
   @END                                                                                                                          
                                                                                                                                 
   # Добавить JSON-массив                                                                                                        
   @APPEND                                                                                                                       
       {"sensor": "humidity", "value": 65.0, "unit": "%"}                                                                        
   @END                                                                                                                          
 ```                                                                                                                             
                                                                                                                                 
 Почему полезно:                                                                                                                 
 - Частый кейс: лог-файлы, JSON-массивы, конфиги                                                                                 
 - Не требует get() чтобы узнать последнюю строку                                                                                
 - Атомарно — всё или ничего
